# Практична робота №1 - Системи штучного інтелекту

Попередня обробка даних та контрольована класифікація за допомогою Python (`scikit-learn`).

## Опис файлів у репозиторії:
- **`LR_1_task_1.py`** — скрипт, що містить рішення для **Завдання 2.1** (базова попередня обробка даних та кодування міток Label Encoding) та **Завдання 2.2** (попередня обробка нових даних відповідно до **Варіанта 1**: бінаризація з порогом 2.2, виключення середнього, MinMax масштабування та нормалізація L1/L2).
- **`LR_1_task_3.py`** — скрипт для **Завдання 2.3** (класифікація даних за допомогою логістичної регресії).
- **`LR_1_task_4.py`** — скрипт для **Завдання 2.4** (класифікація наївним байєсовським класифікатором — GaussianNB).
- **`LR_1_task_5.py`** — скрипт для **Завдання 2.5** (аналіз метрик якості класифікації, побудова ROC-кривих та обчислення площі AUC).
- **`LR_1_task_6.py`** — скрипт для **Завдання 2.6** (класифікація за допомогою машини опорних векторів — SVM).
- **`utilities.py`** — допоміжний файл для візуалізації результатів класифікації.
- **`data_multivar_nb.txt`** — вхідний набір даних для завдань 2.4 та 2.6.
- **`data_metrics.csv`** — набір даних для аналізу метрик у завданні 2.5.

## Використані бібліотеки:
- `numpy`
- `pandas`
- `matplotlib`
- `scikit-learn`
