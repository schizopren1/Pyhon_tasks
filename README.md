# Pyhon_tasks

# Практична робота №1 - Завдання 2.1 та 2.2

Попередня обробка даних за допомогою мови програмування Python та бібліотеки `scikit-learn`.

## Опис файлу:
- **`LR_1_task_1.py`** — скрипт, що містить рішення для **Завдання 2.1** (базова попередня обробка даних та кодування міток Label Encoding) та **Завдання 2.2** (попередня обробка нових даних відповідно до **Варіанта 1**: бінаризація з порогом 2.2, виключення середнього, MinMax масштабування та нормалізація L1/L2).

## Використані бібліотеки:
- `numpy`
- `scikit-learn`
